# 朴素实用版本设计思路

## 目标与判断

用户要求：先写设计思路，再写框架，然后重新设计页面；风格朴素实用、重点鲜明、交互强而实用。

主题改为直接提问：人工智能怎样成为新质生产力。读者应能快速回答三个问题：AI 带来什么变化，变化怎样进入实际生产，什么条件下能形成净收益。

## 只读审计结论

当前工作树干净，HEAD 为 99dd799。仓库与祖先目录未发现额外 AGENTS.md，遵守会话中的工程规则。已阅读入口、模型、数据、样式、测试、工程说明、closure 和发布/打包代码。

1. 现有黑底荧绿、380 节点球体、英文装饰和大幅英雄区偏重视觉展示，与本轮朴素实用要求不匹配。
2. 主要正文与说明多为 10–13px，阅读负担较大；颜色层级复杂，低对比辅助文字影响数据口径阅读。
3. 实验室只能拖动滑块，缺少准确输入、方案保存与并排比较，难以回答“哪种改进更有效”。
4. 产业图景只有整体切换，五步流程不能逐步展开；来源面板缺少查找功能。
5. 现有视频、说明文档、截图与 source manifest 属于旧设计。改版后必须更新，旧证据不能授权新版本。

前四项来自展示优先的同一设计边界，统一调整信息层级与交互任务，不逐项贴补样式。第五项阻止新版作业交付验收，需在实现和正式路径验证后统一重新生成。

## 视觉与内容原则

- 页面采用浅灰底、白色内容区、深色正文，蓝色标注可操作项与关键结论。
- 主段落以 14–16px 为主，摘要说明采用 16px；辅助图注、口径与标签采用 12–13px，并保证对比度。标题采用清晰的中文，不使用装饰性英文段落。
- 每节只回答一个问题。图表旁直接说明单位、年份、来源与适用边界。
- 真实数据、工作场景研究、概念解读、教学模拟用文字标签区分；不能只靠颜色。
- 移除动态球体与绕圈节点，采用简单关系图与规整的选择按钮。
- 保留有解释作用的图表与六个产业场景。复杂度来自交互计算和信息探索。

## 交互任务

1. 选择年份：查看组织 AI 使用比例、当年说明与原始记录。
2. 调整参数：滑块与数字输入同步驱动正式模型。非法/空输入时显示错误、清空当前结果并禁止保存与导出，不能把旧结果继续作为当前结果。
3. 对比方案：保存当前有效参数为 A 或 B，重新通过 simulate 计算两者；比较阶段耗时、总耗时与吞吐量。A/B 为当前页面会话内快照，不跨刷新保存，不复用不可信缓存。
4. 探索流程：点击产业流程某一步，查看具体作用与核查点；切换产业时重置步骤，禁止旧步骤内容与新产业不一致。
5. 查找证据：搜索来源名称、类别、年份和口径；无结果时明确反馈，清空搜索恢复全部。

## 不变量与 non-goals

沿用已核查的历史数据与现有教学模型，不虚构新指标，不训练模型，不接入商业 API。A/B 对比只说明教学参数下的变化，不比较真实企业或作出投资建议。

当前参数、可见结果与 CSV 必须一致；输入失效后必须停止当前结果消费。方案快照只存 validated parameters，读取后重新计算，防止伪造结果与 stale state。所有资源保持相对路径，继续部署到原 GitHub Pages 链接。

## 验收标准

- 新版视觉、导航、字号与移动端通过实际渲染检查，主要内容对比度符合普通文字 4.5:1 目标。
- 原有模型、反事实、导出、来源、行业、导览与五断点验证仍通过。
- 新增正式入口测试验证数字输入、A/B 保存和快照独立性、清空方案、非法输入阻断、流程步骤切换与来源搜索/零结果。
- design → framework → implementation 的执行顺序保留在文档与 Git 变更中。
- 完成独立 requirement closure 和最终复审，重新生成新版 PDF、视频、ZIP 和源码/部署证据。

## 实现后的对抗性复审修正

已发现参数失效后，结果被正确清空但旁边的百分比标签仍显示上一次有效值。新增正式入口断言先复现了 101 输入下仍显示 55% 的失败。统一修正为失效输入的标签显示“—”、设置 aria-invalid、取消预设选择，并在恢复有效参数时同步清除状态，防止控件与当前结果的状态不一致。

上线复查补充：本次新增 model.js / data.js 导出，旧访客若复用未加版本的模块缓存，可能使新入口加载失败。统一采用源码内容 SHA-256 的查询版本键，分别绑定模块 import、app.js 和 styles.css；正式入口测试提供损坏的旧裸路径模块，确认新版仍加载当前模型。内容版本更新后重录演示，不能修改旧录制 manifest 伪装成当前版本。
