# 页面与实现框架

本文件在 REDESIGN_DESIGN.md 之后、页面修改之前编写，承接设计思路中的任务与验收条件。

## 页面结构

| 顺序 / 锚点 | 要回答的问题 | 内容和交互 | 输出 |
|---|---|---|---|
| 01 overview | AI 与新质生产力有什么关系 | 中文主标题、三指标、简单价值链、直接进入实验室 | 清晰主题与导航 |
| 02 trends | 哪些数据支持变化 | 年份选择、折线图、地区比较、成本对照、原始记录表 | 选中年份与对应事实 |
| 03 mechanism | 技术如何变成价值 | 四个规整按钮、作用链与必要条件 | 所选要素解释 |
| 04 industries | 各产业怎样执行 | 六行业标签、传统/AI 对比、五步可点击流程 | 当前行业与当前步骤说明 |
| 05 lab | 怎样判断整体收益 | 三滑块 + 三数字输入、阶段条、结果、预设、A/B 快照和导出 | 当前模拟和独立方案对比 |
| 06 balance | 怎样衡量高质量发展 | 能源估计/预测对比、治理展开内容、来源入口 | 风险与条件 |
| 来源 dialog | 数字是否可靠 | 来源搜索、匹配数量、空结果、全部数据导出 | 过滤后的来源列表 |

桌面用顶部导航和紧凑的章节侧栏；内容最大宽度控制在易读范围。手机切为单列、顶部菜单，表格在自身容器内滚动。

## 文件职责

- dist/index.html：语义结构、中文信息框架与表单控件。
- dist/styles.css：浅色样式、字号、对比度、响应式与焦点状态；重新组织为可维护的分段 CSS。
- dist/data.js：保留来源与真实数据，追加产业步骤解释，避免数字/来源口径变化。
- dist/model.js：现有 simulate + 参数验证；新增 comparePlans，只接受参数并重算，不接受外部结果。
- dist/app.js：所有正式入口交互，状态与 DOM 同步；移除无必要的动画球体实现。
- tests/model.test.mjs：模型与 A/B 的 component tests、伪造结果和非法参数控制。
- tests/browser.mjs：原有正式路径集成测试。
- tests/redesign.mjs：新增交互的正式入口测试、负向控制与计算一致性。
- scripts / docs：更新实际截图、PDF、录制脚本、讲解、source manifest、部署与打包证据。

## 状态与正式因果链

数字输入/滑块 → 读取并验证完整参数 → simulate → 阶段/总耗时/吞吐量 → DOM 与 CSV。

失效输入 → currentSimulation = null → 当前结果不可用 → 保存与导出禁用 → 明确错误。

保存 A/B → 拷贝已验证的参数 → 独立参数快照 → comparePlans 重新 simulate → 两方案差异 → 对比表 / CSV。

产业选择 → 当前行业对象 → 步骤重置为 0 → 当前步骤对象 → 作用 / 核查点。后续点击只读取当前行业的步骤。

来源搜索 → 原始 sources 数组过滤 → 同一匹配集的数量和 DOM；空集必须显示“没有找到匹配来源”。

## 验证顺序

先新增缺失功能测试并确认预期失败；再实现；focused tests 与原有 negative controls；读取本轮用户请求和两份设计文件重新 closure；对抗性复审；完整检查、桌面/手机视觉检查；发布同一仓库、从公网运行两套 browser tests、逐资源哈希核对；重做新版视频/PDF/ZIP，禁止沿用旧资料宣称新版完成。
