## 证据边界

model / compare tests 是 COMPONENT_CAPABILITY。两套 browser tests 从正式 HTML 入口操作真实控件，读取当前阶段、最终结果和真实下载文件，提供 FORMAL_PATH_INTEGRATION。改变参数和方案确实改变模型结果、可见表格与 CSV；失效输入、关闭 AI、清空方案与产业切换会明确改变状态，不能仅以元素存在或被记录替代。

网站引用外部研究，不声称独立复现其企业收益；产业流程是教学机制说明。没有声称本项目实现真实 AI 预测或部署产业系统，因此不拿 fixture 当作 AI 系统 INDEPENDENT_EVALUATION。
